# Gemma trial blocked by shared provider quota

The key authenticated successfully. A small JSON connectivity probe returned a
response from Google AI Studio at reported cost zero. Seven requests containing
the telemetry migration task received HTTP 429. The retained provider error
identifies its shared free pool as the limit.

The first two case attempts used the initial settings. The final case attempt
used a 2048-token response budget with reasoning disabled and stopped after
its first provider error. This attempt produced no migration response.

Model patch validation rate is unmeasured. Retry when capacity becomes available,
or explicitly configure a Google AI Studio key through OpenRouter BYOK.
The current adapter preserves provider diagnostics, excludes credentials and
stops a case after a provider HTTP error.
