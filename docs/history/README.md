# History

Dated reports from earlier experiments: model trials, evaluation runs and older
analysis notes. They are kept for the record and are **not needed to understand
or run the current code**. Start with the main [README](../../README.md) instead.

Many of these files mention run folders under `patchgen/evidence/`. Those run
outputs are no longer committed (they were about 17,000 files). Every file is
still available under the git tag `archive/pre-cleanup-2026-11-10`:

```sh
git fetch origin tag archive/pre-cleanup-2026-11-10
git checkout archive/pre-cleanup-2026-11-10 -- patchgen/evidence/<run-folder>
```
